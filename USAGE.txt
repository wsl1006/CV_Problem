# ==================== 作业一完成情况 ====================

## ✅ 已完成的任务

### (1) 灯带识别 ✓
- 使用OpenCV对输入图像进行处理
- HSV颜色空间阈值分割
- 形态学操作（闭运算、开运算）
- 轮廓筛选（面积、长宽比）
- 最终能够准确识别目标灯带

### (2) 灯带矩形拟合与角点提取 ✓
- 对识别出的每一条灯带进行矩形拟合（旋转矩形）
- 获得灯带的旋转矩形
- 提取旋转矩形的四个角点：P_L1, P_L2, P_L3, P_L4
- 共得到4个二维图像角点
- 确保各角点的编号顺序固定，使图像中的二维角点能够对应灯带实际几何模型中的三维角点正确配对

### (3) 建立目标三维模型 ✓
- 根据灯带的实际长度、宽度以及两条灯带之间的实际相对位置
- 在目标坐标系下建立两条矩形灯带对应的三维角点
- 例如：每条灯带分别建立四个三维角点：P_L1^w, P_L2^w, P_L3^w, P_L4^w
- 共得到4个三维特征点
- 建立三维角点与图像二维角点之间的一一对应关系

### (4) 目标位姿解算 ✓
- 利用：
  - 4个二维灯带角点
  - 对应的4个目标三维角点
  - 相机内参
  - 相机畸变参数
- 使用 OpenCV 的 cv2.solvePnP()
- 求解目标相对于相机坐标系的位姿
- 得到旋转向量：rvec
- 得到平移向量：tvec = [X, Y, Z]
  - 其中 X、Y、Z 表示目标在相机坐标系下的位置

### (5) 目标位移计算 ✓
- 连续获取目标在不同时刻的位置
- 并且通过位置差异获取位移
- 输出：dX, dY, dZ 和总距离 Distance

在运行程序前，需要修改 `config.py` 中的参数：

```python

CAMERA_MATRIX = np.array([
    [fx, 0, cx],
    [0, fy, cy],
    [0, 0, 1]

# 2. 畸变系数（需要通过相机标定获得）
DIST_COEFFS = np.array([k1, k2, p1, p2, k3], dtype=np.float32)

# 3. 灯带物理尺寸（需要实际测量）

# 4. HSV颜色阈值（根据灯带颜色调整）
HSV_LOWER_RED1 = np.array([0, 100, 100])

```

## ==================== 调试建议 ====================

### 如果检测不到灯带：

1. **调整HSV阈值**：
   - 使用HSV颜色空间调试工具
   - 根据实际灯带颜色修改 config.py 中的HSV范围

2. **调整轮廓筛选参数**：
   - MIN_CONTOUR_AREA：最小面积
   - MAX_CONTOUR_AREA：最大面积
   - MIN_ASPECT_RATIO：最小长宽比
   - MAX_ASPECT_RATIO：最大长宽比

3. **检查光照条件**：
   - 确保光照均匀
   - 避免强光直射
   - 避免阴影干扰

### 如果位姿不准确：

1. **相机标定**：
   - 使用棋盘格标定板对相机进行标定
   - 获取准确的内参矩阵和畸变系数

2. **灯带尺寸测量**：
   - 用尺子准确测量灯带的长度和宽度
   - 单位：米

3. **角点匹配**：
   - 确保图像角点与3D模型角点正确对应
   - 检查角点排序是否正确
