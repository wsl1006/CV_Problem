# 灯带识别与目标位移解算系统

**题目一：基于OpenCV的灯带识别与目标位移解算**

## 项目简介

本项目实现了一个基于OpenCV的计算机视觉系统，用于识别场景中的灯带目标，并计算其相对于相机的位姿和位移信息。

## 功能特点

### 已实现功能

1. **灯带识别**
   - 使用HSV颜色空间进行颜色阈值分割
   - 支持红色和蓝色灯带检测
   - 形态学操作去噪
   - 轮廓筛选（面积、长宽比过滤）

2. **矩形拟合与角点提取**
   - 对检测到的灯带进行旋转矩形拟合
   - 提取并排序矩形的4个角点
   - 获得图像坐标系中的2D角点坐标

3. **3D模型建立**
   - 根据灯带的实际物理尺寸建立3D模型
   - 支持单条和多条灯带的3D坐标系建立

4. **目标位姿解算（PnP）**
   - 使用cv2.solvePnP()求解相机到目标的位姿
   - 计算旋转向量（rvec）和平移向量（tvec）
   - 将旋转向量转换为欧拉角（Roll, Pitch, Yaw）

5. **目标位移计算**
   - 连续跟踪目标在不同时刻的位置
   - 计算相对于初始位置的位移（dX, dY, dZ）
   - 计算总位移距离

## 使用方法

### 1. 配置参数

在运行前，需要在 `core/config.py` 中配置以下参数：

- **相机内参矩阵**（`CAMERA_MATRIX`）：根据相机标定结果填写
- **畸变系数**（`DIST_COEFFS`）：根据相机标定结果填写
- **灯带物理尺寸**：
  - `LIGHT_LENGTH`：灯带长度（米）
  - `LIGHT_WIDTH`：灯带宽度（米）
  - `LIGHT_SPACING`：灯带间距（米）
- **HSV颜色阈值**：根据实际灯带颜色调整

### 2. 运行程序

```bash
python main_rgb.py
```

### 3. 操作说明

程序运行后会打开相机并显示实时图像：

- **按 'q'**：退出程序
- **按 's'**：保存当前帧到 `results/` 目录
- **按 'r'**：重置初始位置（将当前位置设为新的参考点）

### 4. 输出信息

程序实时显示以下信息：

1. **原始相机图像**：实时视频流
2. **检测到的灯带**：用绿色矩形框标出
3. **旋转矩形框**：红色矩形框
4. **灯带的4个角点**：红色圆点标记，标注为P1-P4
5. **当前目标位置**：
   - X, Y, Z 坐标（米）
6. **目标相对于初始位置的位移**：
   - dX, dY, dZ（米）
   - Distance：总位移距离（米）
7. **坐标轴可视化**：
   - 红色：X轴
   - 绿色：Y轴
   - 蓝色：Z轴

## 算法流程

```
输入图像
    ↓
灯带检测（HSV阈值 + 形态学处理）
    ↓
轮廓筛选（面积、长宽比）
    ↓
矩形拟合与角点提取
    ↓
建立3D模型（世界坐标系）
    ↓
PnP求解（计算rvec和tvec）
    ↓
位移计算 & 欧拉角转换
    ↓
结果可视化与输出
```

## 核心算法说明

### 1. 灯带识别

- **颜色空间转换**：BGR → HSV
- **阈值分割**：使用cv2.inRange()
- **形态学操作**：闭运算填充孔洞，开运算去除噪声
- **轮廓检测**：cv2.findContours()
- **轮廓筛选**：根据面积和长宽比过滤

### 2. 矩形拟合与角点提取

- **最小外接旋转矩形**：cv2.minAreaRect()
- **角点排序**：按照左上、右上、右下、左下的顺序排列

### 3. PnP位姿解算

- **输入**：
  - 图像2D点（灯带角点）
  - 对应的3D世界坐标点
  - 相机内参和畸变系数
- **输出**：
  - 旋转向量（rvec）
  - 平移向量（tvec）
- **方法**：cv2.solvePnP()

### 4. 位移计算

```python
dx = tvec_current[0] - tvec_initial[0]
dy = tvec_current[1] - tvec_initial[1]
dz = tvec_current[2] - tvec_initial[2]
distance = sqrt(dx² + dy² + dz²)
```

## 注意事项

1. **相机标定**：
   - 在实际使用前，必须对相机进行标定，获取准确的内参矩阵和畸变系数
   - 可以使用棋盘格标定板进行标定

2. **灯带尺寸**：
   - 需要准确测量灯带的物理尺寸（长度L和宽度W）
   - 尺寸单位为米

3. **HSV阈值调整**：
   - 根据实际灯带颜色和环境光照调整HSV阈值
   - 可以使用HSV调试工具找到最佳阈值

4. **坐标系定义**：
   - 世界坐标系：以灯带中心为原点，Z=0平面
   - 相机坐标系：以相机光心为原点，Z轴指向前方

## 测试建议

1. **打印标定板**：可以打印一个带有标志的平面矩形，保持pitch=0
2. **固定灯带尺寸**：使用实际的LED灯带或打印彩色矩形
3. **良好的光照条件**：避免强光直射和阴影
4. **逐步调试**：先确保能检测到轮廓，再调整PnP参数
